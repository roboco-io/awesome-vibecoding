## Review limits

The review inspected public documentation, GitHub metadata/releases/licenses, URL reachability, and duplicates against the latest repository content. It did not install submitted applications, deploy a site, audit source code for security, or verify predictive/benchmark claims. Inclusion is a curated pointer, not a security certification or endorsement of every product claim.

The six accepted resources are included in all three README languages. Their issues must be closed only after the corresponding repository update is published successfully.
